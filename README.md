# Hotel Management System

## Project Overview
A Python-based hotel management application that stores hotel data using JSON files and supports different user roles.

## Features
- Admin, Staff, and Guest login options
- Room management: add, update, and delete rooms
- Guest and staff management
- Room booking, updating, and cancellation
- View rooms and booking records
- JSON-based data storage

## Technologies Used
- Python
- JSON

## Project Files
- `Hotel_Management.py` — Main application
- `Admin.py` — Admin operations
- `Staff.py` — Staff operations
- `Guest.py` — Guest operations
- `Hotel_Data.json` — Hotel data storage
- `extra.py` — Supporting module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Run `Hotel_Management.py` from the project directory.
